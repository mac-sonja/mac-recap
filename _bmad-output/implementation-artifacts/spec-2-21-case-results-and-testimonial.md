## Intent

**Problem:** A case history will close on its own outro page, made only of its Risultati and Testimonial (SCP 2026-10-26, C24), but the case Details step only asks Contesto and Soluzione. The old free-text Risultati (`context_form.results`) has been hidden since #63.

**Approach:** Give the case the client's structured Risultati (up to 3 label + value rows) and Testimonial (quote + author), stored on `context_form`, saved through the same rules as the client (#88), and shown in the case Details step as cards **06 Risultati** and **07 Testimonial** after Soluzione, reusing the client panel's fields.

## Boundaries & Constraints

**Always:** Same limits and rules as the client: ≤3 rows, label ≤80, value ≤20, quote ≤600, author ≤120 (code points, trimmed); a row counts only when both parts are filled; an author needs a quote; both optional and never needed for **Avanti** or Generate (NFR6: form answers are never material). Autosave on blur, as the client panel. Every save records a `details_saved` case event with `{ field: 'results' | 'testimonial' }` only, never the text, and puts the previous value back if the event fails (as `saveDetailsField`). `fill details` authorizes it. Forward-only migration; RLS stays denied; service-role functions with the same advisory lock and live-case check as `save_context_field`.

**Never:** No AI, no layout or outro rendering (Story 3.4). No change to the client panel's behaviour. The old free-text `context_form.results` is dropped with its data (decision: only one test value on mac-recap-dev, as #88 did for clients); no migration of it into rows.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Save rows | 2 complete rows, 1 empty | 2 results stored in order; event `details_saved {field:'results'}` | N/A |
| Half row | label only | message "Scrivi sia cosa misuri sia il numero."; last saved row kept | not sent |
| Author only | author, no quote | "Manca la frase."; saved pair kept | not sent |
| Same value | stored list sent again | nothing written, no event | N/A |
| Over limit | value of 21 chars | inline length error; server refuses | `INVALID_INPUT` |
| Deleted case | any save | nothing written | `NOT_FOUND` |

# MAC Recap – Specifiche UI (tasti, tab, testi, border-radius)

Fonte: artefatto "MAC Recap (Configuratore)". Valori in px, come da CSS.

## 1. Font

| Uso | Font |
|---|---|
| UI | -apple-system / SF Pro Text / Geist |
| Titoli | -apple-system / SF Pro Display / Geist |
| Serif (logo, saluto) | Instrument Serif (italic) |
| Mono (numeri, shortcut) | Geist Mono |

Base: 14px, line-height 1.45, letter-spacing -0.006em.

## 2. Tasti (`.btn`)

Forma: pillola (border-radius 999px), font-weight 600, gap icona/testo 7px.

| Taglia | Altezza | Padding orizz. | Font-size |
|---|---|---|---|
| Small (`.sm`) | 28 | 11 | 12.5 |
| Default | 34 | 14 | 13.5 |
| Large (`.lg`) | 42 | 20 | 14.5 |
| Solo icona (`.icon`) | 34×34 (sm: 28×28) | 0 | – |

| Variante | Sfondo | Testo |
|---|---|---|
| Primario (`.pri`) | #d4ff3f (hover #c3ef2c) | #121500 |
| Secondario (`.sec`) | --fill-2 | --fg |
| Ghost (`.ghost`) | trasparente (hover --fill) | --fg-2 |
| Danger (`.danger`) | --red-bg | --red |
| Disabilitato | opacità 0.4 | – |

Stato premuto: scale(0.97). Eccezione: tasto "Crea" in sidebar con radius 10px.

## 3. Tab

### Segmented control (`.seg`)
- Contenitore: padding 3px, radius 10px, sfondo --fill-2
- Tab: altezza 28px, padding 0 12px, radius 7px, font 13px / 500
- Tab attiva: testo --fg, "thumb" bianco (--surface) con ombra, radius 7px
- Contatore nel tab: 11.5px, --fg-3
- Variante solo icone: padding 0 9px

### Step wizard (`.steps`)
- Contenitore: padding 3px, radius 12px, 3 colonne
- Tab: altezza 36px, font 13.5px / 500
- Thumb attivo: radius 9px
- Numero step: Geist Mono 11.5px

### Navigazione sidebar (`.nav-i`)
- Altezza 34px, padding 0 10px, radius 9px, font 13.5px / 500
- Attivo: sfondo --fill-2, testo --fg
- Contatore: 11.5px

### Tab bar mobile (≤760px)
- Voce: font 10.5px / 600, padding 5px 0, icona sopra il testo

## 5. Border-radius

### Token
| Token | Valore | Uso |
|---|---|---|
| --r-sm | 8px | (definito, poco usato) |
| --r-md | 12px | (definito, poco usato) |
| --r-lg | 18px | Card, tabelle, riepiloghi, empty state |

### Valori effettivi per componente
| Radius | Componenti |
|---|---|
| 999px | Tasti, pill, chip, switch |
| 22px | Dialog |
| 20px | Logo cliente grande |
| 18px | Card, tabelle (--r-lg) |
| 16px | Dropzone, command palette |
| 14px | Canvas editor, toast, righe ordinabili, card tabella mobile |
| 12px | Step wizard, file, claim, opzioni, linkbox, logo cliente, immagini |
| 10px | Input/textarea/select, segmented, sidebar "Crea", thumbnail |
| 9px | Voci nav, search bar comandi, thumbnail media, thumb step |
| 7px | Tab del segmented |
| 6px | Tag, checkbox, focus ring, kbd (5px) |
| 50% | Avatar, radio, dot |

Nota: la scala reale non segue i token (--r-sm/--r-md sono quasi inutilizzati). Consiglio di consolidare in: 6 / 10 / 12 / 18 / 22 / 999.
